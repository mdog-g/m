# Photos

Drop salon photos into this folder using these exact filenames and the gallery
on the site will pick them up automatically — no code changes needed:

- gallery-1.jpg
- gallery-2.jpg
- gallery-3.jpg
- gallery-4.jpg
- gallery-5.jpg
- gallery-6.jpg

Any image size works — photos are cropped to fit a portrait frame — but
square or portrait shots (roughly 4:5) will look best.
