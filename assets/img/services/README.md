# Service photos

Drop a photo in with the exact filename below and it will appear on the site automatically — no code changes needed. Until a file exists, that spot shows an elegant placeholder.

| Filename | Used for | Suggested shape |
|---|---|---|
| `colouring.jpg` | Hair Colouring card | Portrait, 4:5 |
| `balayage.jpg` | Balayage & Foils card | Portrait, 4:5 |
| `extensions.jpg` | Hair Extensions card | Portrait, 4:5 |
| `styling.jpg` | Cutting & Styling card | Portrait, 4:5 |
| `balayage-transformation.jpg` | Signature Service featured card | Portrait, 4:5 |

Aim for at least 1200px on the long edge. JPG or PNG both work — just keep the filename and extension exact (all lowercase).
