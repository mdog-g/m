# Muse Hair Co

Marketing website for Muse Hair Co, a hair salon in Toukley, NSW.

Static site — no build step. Open `index.html` directly or serve the folder with any static file server.

```
index.html
assets/
  css/style.css
  js/main.js
  img/            logo + favicon assets (cropped from the studio's own Instagram badge)
```

Booking is handled externally via [Fresha](https://www.fresha.com/a/muse-hair-co-toukley-3-315-main-road-qrs86ser/all-offer?menu=true&pId=719013).
